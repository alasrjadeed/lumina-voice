What you get

Made for long listening,
not long loading.

Every detail is tuned for weak connections, small screens and stories that deserve your full attention.

◉

Offline-first shell

App, state, ads and downloaded episodes stay on the device. Archive.org streams need a connection unless cached.

♫

Light on bandwidth

Public-domain audio streamed directly from Archive.org. No first-party media server, no bundled story files.

▤

Subtitles & captions

Auto captions with a simple Auto / Off switch, plus a subtitle studio for your own tracks.

★

Ratings & reviews

Signed-in listeners can rate titles and write reviews. Supabase keeps one of each per title.

▣

Native tablet app

Capacitor build with media keys, safe-area layout and a ~6 MB APK — only ad audio is bundled; titles stream from Archive.org.

◐

Radio, ready when you are

Broadcast studio and live radio are built in but paused until stream resources are available.

How it works

Your library, on your terms.

The web app and the tablet app share one catalogue and one account. Pick up a story on one device, finish it on the other.

1

Browse or import

Start with the curated catalogue or pull public-domain titles from Archive.org.

2

Set your media base

Point the app at your own audio host, or keep everything local on the device.

3

Sign in, keep your place

Supabase Auth and profiles sync your account, roles, ratings and reviews.

4

Listen anywhere

Queue the next episode, lock the screen, and let the story run — online or off.

Questions

Who can listen, and what is saved?

Clear answers for listeners and new contributors.

Who developed Lumina Voice?

AL ASAR JADEED developed Lumina Voice. Web: www.alasarjadeed.com.

Can another person sign in with a different email?

Yes. Anyone can create a free profile with their own email. Everyone sees the same public Archive.org catalogue; only info@alasarjadeed.com has admin access.

What saved data can another listener see?

Your library, playback positions, history, imported Archive titles, artwork, subtitles and settings belong to your own account and cannot be edited by other accounts. Public ratings, reviews and the shared catalogue are visible to everyone. No audio files are uploaded; only metadata syncs.

Get started

Run it yourself.

Clone the repository, add your public Supabase URL and publishable key, then build for web or tablet.

terminal
# clone and install
git clone https://github.com/alasrjadeed/lumina-voice.git
cd lumina-voice
npm install

# add your public Supabase values to .env.local
# VITE_SUPABASE_URL=...
# VITE_SUPABASE_PUBLISHABLE_KEY=...

# run locally
npm run dev

# web build, checks, and native APK
npm run lint && npm test && npm run build
./gradlew clean assembleDebug   # in android/
